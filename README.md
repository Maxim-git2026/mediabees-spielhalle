# MediaBees Spielhalle

Kleine Spielhalle für die 404-Seite von [mediabees.de](https://mediabees.de) als WordPress-Plugin
„MediaBees Spielhalle“: Käfer-Jagd, Bienenstich, Revierflug, Bienentanz, A40-Flitzer, Website-Abriss, Wespennest, Wabenwacht, Pollenpfad, Wabenbau, Bienen-Solitär, Hummelhopser, Honigdieb, Honigknaller und Honigflipper, jeweils mit Top-10-Rangliste.

- Bauen: `./build.sh` → `dist/mediabees-arcade-<version>.zip`
- Einbinden: automatisch auf der 404-Seite oder per Shortcode `[mediabees_arcade]`
- Details für die Weiterentwicklung: siehe [CLAUDE.md](CLAUDE.md)
